# LibraSpace — Library Seat & Resource Booking System

A simple front-end library booking system built with **HTML, CSS, and JavaScript**.

## Features

- Responsive library dashboard
- 12-seat selection system
- Date and time slot selection
- Seat availability checking
- Seat and resource booking
- My Bookings section
- Booking cancellation
- Browser `localStorage` for saving bookings
- Mobile-friendly layout

## Run Locally

Open `index.html` in a browser.

No server or database is required for this version.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this project.
3. Make sure `index.html` is in the repository root.
4. Go to **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save and wait for GitHub Pages to publish the site.

## Important

Bookings are stored in the browser's `localStorage`. This means the data is local to the browser/device and is not shared between users.
